### Video Doorbell DPID Definition

| DPID |              Function               |         Identifier         | Data Transfer Type | Data Type | Support Automation |                    Function Attributes                     |
| :--: | :---------------------------------: | :------------------------: | :----------------: | :-------: | :----------------: | :--------------------------------------------------------: |
|  1   |               Switch                |           switch           |    Bidirectional   |  number   |        Yes         | Value range: 00-FF, binary 1111 1111, each bit represents one channel, up to 8 channels can be set at the same time |
|  2   |         Channel 1 countdown         |        countdown_1         |    Bidirectional   |  number   |         No         |                                                            |
|  4   |     Motion detection sensitivity    |        motion_sens         |    Bidirectional   |   enum    |         No         |            1: low, 2: medium, 3: high                      |
|  5   |      Motion detection frequency     |      motion_interval       |    Bidirectional   |  number   |         No         |  Minimum interval between two motion detection triggers    |
|  6   |        Video transmission mode      |        video_format        |   One-way, report  |   enum    |         No         |       1: MJPEG_RAW, 2: H264_RAW, 3: H264_WEBRTC            |
|  7   |        Audio transmission format    |        audio_format        |   One-way, report  |   enum    |         No         |           1: PCM, 2: a-law, 3: μ-law, 4: Opus              |
| 101  |        Device initiates a call      |    device_request_call     |   One-way, report  |  number   |         No         | 1: device is in calling state, 2: device is not in calling state (deprecated) |
| 102  |             Battery level           |        electricity         |   One-way, report  |  number   |        Yes         |         Value range: 0-1000, step 1, unit: per mille       |
| 103  |          Low battery alert          |      low_power_alert       |       One-way      |  number   |        Yes         |         1: low battery alert; 2: not in alert state        |
| 104  |         IR fill light setting       |       ir_fill_light        |  One-way, downlink |  number   |         No         |           1: enable fill light; 2: disable fill light      |
| 105  |          Motion detection           |    motion_detect_enable    |  One-way, downlink |  number   |         No         |            1: enable detection; 2: disable detection       |
| 106  |       Motion detection alert        |    motion_detect_alert     |   One-way, report  |  number   |        Yes         |              1: alert; 2: not in alert state               |
| 107  |   Reason for device-initiated call  | device_request_call_reason |   One-way, report  |  number   |         No         |     Enum, 1: button press; 2: motion detected              |
| 108  |       Motion detection action       |    motion_detect_action    |  One-way, downlink |  number   |         No         | Enum; 1: do nothing; 2: take a snapshot; 3: call the user; 4: take a snapshot and call the user |
| 109  |        Whether user answers         |        user_answer         |  One-way, downlink |  number   |         No         |               Enum, 1: answer; 2: do not answer            |
| 110  |             Session id              |         session_id         |  Bidirectional     | string 4byte |      No         | This value is a random id for a call, generated by the device or the app. When the device returns a query result and this value is empty, it means the device is not in a call |
| 111  |   User requests device video/audio   |          user_call         |  One-way, downlink |  number   |         No         | The user actively initiates a call and it needs to work together with session id. 1: user requests; 0: user cancels the request |
| 112  |          Communication type         |         call_type          |    Bidirectional   |  number   |         No         |  Enum, 1: video; 2: audio; 3: video + audio                |
| 113  |      User closes session_channel    |     user_close_reason      |  One-way, downlink |  number   |         No         | Enum, 0: no reason, meaning not in a call; 1: closed by user; 2: closed due to timeout |
| 114  |        Device closes session        |    device_close_reason     |   One-way, report  |  number   |         No         | Enum, 0: no reason, meaning not in a call; 1: user did not answer; 2: closed due to timeout |
| 115  |          Video resolution           |      video_resolution      |    Bidirectional   |  number   |         No         |                 Enum, 1: 720, 2: 480                       |
| 116  |            Video frame rate         |         video_fps          |    Bidirectional   |  number   |         No         |              Value range: 1-30, step 1                     |
| 117  |       Device push type enum         |         push_type          |  One-way, downlink |  number   |         No         | Enum; 1: LAN communication; 2: WAN communication; 3: LAN and WAN communication |
| 118  |     Protocol version in use (none)  |                            |                    |           |                    |                                                            |
| 119  |       Whether device answers        |       device_answer        |  One-way, report   |  number   |         No         |               Enum, 1: answer; 2: do not answer            |
| 120  |       Enter deep sleep time         |      enter_sleep_time      |    Bidirectional   |  number   |         No         | Value range: 0-1440; 0: disable active call, 60: one hour, 1440: permanent |
| 121  | Device source 1 image rotation      |   device_image_rotation    |    Bidirectional   |  number   |         No         |   Enum, 0: 0 degree, 1: 90 degrees, 2: 180 degrees, 3: 270 degrees |
| 122  |  User source 1 image rotation       |    user_image_rotation     |    Bidirectional   |  number   |         No         |   Enum, 0: 0 degree, 1: 90 degrees, 2: 180 degrees, 3: 270 degrees |
| 123  |      Video resolution width         |   video_resolution_width   |    Bidirectional   |  number   |         No         |              Value range: 320-1920                        |
| 124  |      Video resolution height        |   video_resolution_high    |    Bidirectional   |  number   |         No         |              Value range: 320-1920                        |
| 125  |              channel                |           token            |    Bidirectional   |  string   |         No         |        Token of the current call of the device             |
| 126  |    Channel of audio played by device |   device_audio_channel     |    Bidirectional   |  string   |         No         | Channel of audio played by the device. If the device is currently playing, a new play request returns the currently playing channel |
| 127  |          Current call list          |         token_list         |  One-way, downlink |  string   |         No         | Current call list, e.g. ["token1", "token2"]           |
| 128  |            Signal source            |       signal_source        |    Bidirectional   |  number   |         No         | Device audio/video signal source, e.g. switch between two cameras, default 0 |
| 129  | Device source 2 image rotation      |   device_image_rotation    |    Bidirectional   |  number   |         No         |   Enum, 0: 0 degree, 1: 90 degrees, 2: 180 degrees, 3: 270 degrees |
| 130  |  User source 2 image rotation       |    user_image_rotation     |    Bidirectional   |  number   |         No         |   Enum, 0: 0 degree, 1: 90 degrees, 2: 180 degrees, 3: 270 degrees |
