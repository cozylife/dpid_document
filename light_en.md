### Light DPID Definition

| DPID  |            Function            |      Identifier      | Data Transfer Type | Data Type | Support Automation | Function Attributes |
| :---: | :----------------------------: | :------------------: | :----------------: | :-------: | :----------------: | :---: |
|   1   |             Switch             |     switch_led       |    Bidirectional   |   enum    |        Yes         | Enum: 0-2 <br> 0: off <br> 1: on |
|   2   |          Working mode          |      work_mode       |    Bidirectional   |   enum    |         No         | Enum: 0-2; <br>0: static, 1: scene, 2: music_out, 3: diy, 4: music_inc, 5: 2d_text, 6: 2d_diy, 7: picture |
|   3   |        Color temperature       |     temp_value       |    Bidirectional   |  number   |         No         | Value range: 0-1000; 65535 (0xffff) means this value is invalid |
|   4   |           Brightness           |    bright_value      |    Bidirectional   |  number   |         No         | Value range: 10-1000 |
|   5   |              Hue               |      hue_value       |    Bidirectional   |  number   |         No         | Value range: 0-360; 65535 (0xffff) means this value is invalid |
|   6   |           Saturation           |      sat_value       |    Bidirectional   |  number   |         No         | Value range: 0-1000; 65535 (0xffff) means this value is invalid |
|   7   |             Scene              |     scene_data       |    Bidirectional   |  string   |         No         | Value: 00HHHHSSSSTTTT; <br>00: scene number; 16 dynamic scenes in total, with fixed transition modes (0~3 gradient, 4~7 jump, 8~b breathing, c~f strobe) <br>Single color, dual color, tri color, seven color (note that some effects cannot be done with single color)<br>H (hue: 0-360, FFFF means only the T value is used); <br>S (saturation: 0-1000, FFFF means only the T value is used);<br>T (color temperature: 0-1000, FFFF means only the HS value is used);<br> Note: HST supports up to 7 groups; all colors share the same brightness value, and all dynamic modes share the same speed value, but the multiplier can differ; at most 1+7*6=43 bytes are needed |
|   8   |             Speed              |     speed_value      |    Bidirectional   |  number   |         No         | Speed shared by dynamic scenes, value range: 10-1000 |
|   9   |       Power-off memory         |    power_memory      |    Bidirectional   |  number   |         No         | Value range: 0-1 |
|  10   |     Microphone sensitivity     |  sensitivity_value   |    Bidirectional   |  number   |         No         | Value range: 1-10 |
|  11   |           RGB pin order        |      rgb_turn        |    Bidirectional   |   enum    |         No         | Value range: 0-5, default 0;<br>0: GRB; 1: RGB; 2: GBR; 3: RBG; 4: BRG; 5: BGR;<br>When adjusting the pin order, the app should guide the user: which color is currently lit and how many LEDs are lit, so as to calculate the actual number of LEDs in use |
|  12   |       Number of LED chips      |     chip_point       |    Bidirectional   |  number   |         No         | Number of addressable LED chips, value range: 10-1000 |
|  13   |           Countdown            |      countdown       |    Bidirectional   |  number   |         No         | Value range: 0-86400, unit: s |
|  14   |        Periodic timer          |    normal_timer      |    Bidirectional   |  string   |         No         | Supports local timers, invalid after restart |
|  15   |          Music mode            |     music_index      |    Bidirectional   |   enum    |         No         | Value range: 0-3, corresponding to different music effects |
|  16   |  Addressable static color      | dream_static_color   |    Bidirectional   |  string   |         No         | Used to control the whole addressable LED segment data&lt;br/&gt;Value: HHHHSSSSTTTT... &lt;br/&gt;Whole control: HHHHSSSSTTTT with only one color group&lt;br/&gt;Separate control: HHHHSSSSTTTT... requires 30 color groups&lt;br/&gt;H (hue: 0-360, FFFF means only the T value is used); &lt;br/&gt;S (saturation: 0-1000, FFFF means only the T value is used);&lt;br/&gt;T (color temperature: 0-1000, FFFF means only the HS value is used); |
|  17   | Addressable real-time control  | dream_control_data   |     Write-only     |  string   |         No         | Used for fast response to addressable segment control; the device only executes this command and does not reply.&lt;br/&gt;Value: 01HHHHSSSSTTTT&lt;br/&gt;01: addressable strip segment number (range 0-29; when the segment number is FF, it means controlling the whole segment, and in this case it cannot be written to storage) |
|  18   |   Addressable scene content    |  dream_scene_value   |    Bidirectional   |  string   |         No         | Combine different colors and animations to form a custom scene&lt;br/&gt;Value: HHHHSSSSTTTT...000102...FFFFSS&lt;br/&gt;HHHHSSSSTTTT... : fixed 7 color groups&lt;br/&gt;000102...FFFF: animation list (00 jump + 01 gradient + 02 meteor... 10 in total, pad with FF if insufficient)&lt;br/&gt;SS: execution speed of the scene, value range 00-64 |
|  19   |  Addressable scene index       |  dream_scene_index   |    Bidirectional   |  number   |         No         | Scene ID; 0-19 are DIY scenes, 20-255 are built-in scenes. When switching scenes, only this DPID needs to be executed |
|  20   | Addressable static fade        | dream_static _fade   |    Bidirectional   |   enum    |         No         | 0: fade off; 1: fade on |
|  21   |   Phone mic collected data     |      music_fft       |     Write-only     |  string   |         No         | None |
|  23   |        Battery level           |     dump_energy      |      Read-only     |  number   |         No         | 0-100 |
|  24   |        Battery voltage         |    cell_voltage      |      Read-only     |  number   |         No         | Lower bound: 0; upper bound to be confirmed; unit: mV |
|  25   |        Input current           |  incoming_current    |      Read-only     |  number   |         No         | Lower bound: 0; upper bound to be confirmed; unit: mA |
|  26   |        Output current          |   current_output     |      Read-only     |  number   |         No         | Lower bound: 0; upper bound to be confirmed; unit: mA |
|  27   |        Device temperature      |     temperature      |      Read-only     |  number   |         No         | -127℃ ~ 1000℃; input value 0-1127 |
|  28   |        Charging state          |   charging_state     |      Read-only     |   enum    |         No         | Value range: 0-2; 0: disconnected, 1: charging, 2: fast charging |
|  30   |      Built-in scene index      |     scene_index      |     Read/write     |   enum    |         No         | Enum type: 1-100 |
|  31   |   Bluetooth classic name       |  classic_bt_name     |     Read/write     |  string   |         No         | 0-255 bytes, encoded in Unicode UTF-8 |
|  32   |       RGB color correction     |     rgb_adjust       |     Read/write     |  string   |         No         | Three values, per mille, length 12: RRRRGGGGBBBB |
|  33   |      LED chip point details    |     point_info       |     Read/write     |  string   |         No         | Three values: point count + length + width, length 12: NNNNHHHHWWWW |
|  34   |         Signal source          |    signal_source     |     Read/write     |  number   |         No         | Lower bound: 0; upper bound to be confirmed |
|  35   |  Addressable matrix move mode  |      dir_index       |    Bidirectional   |   enum    |         No         | Value range: 0-6;<br> 0: fixed; 1: move left; 2: move right; 3: move down; 4: move up; 5: blink; 6: breathe |
|  36   |     Total text char count      |    text_char_num     |     Write-only     |  number   |         No         | Value range: 0-10 |
|  37   |   Single text char content     |   text_char_point    |     Write-only     |  string   |         No         | Combine different text characters for display, Value: 01HHHHSSSSTTTT... |
|  38   |    Text char change mode       | text_char_modecolor  |     Write-only     |  string   |         No         | Color mode of text characters, Value: 01HHHHSSSSTTTT; <br>01: color mode number; 6 color modes in total, 1: solid color, all characters share one color; 2-5: characters change color dynamically |
|  39   |   Text border/bg color         |  text_border_color   |     Write-only     |  string   |         No         | Text border mode and background color, Value: 00HHHHSSSSTTTT; <br>00: border mode, 0-3; HHHHSSSSTTTT: character background color; if there is no color, set TTTT to 0x0000 |
|  40   |     2D DIY points              |    diy_2d_point      |     Write-only     |  string   |         No         | Used to display 2D DIY points, no reply, Value: 000000HHHHSSSS0000HHHHSSSS...; <br>00: plane 0; the first packet must set the second highest bit to 1, and the last packet must set the highest bit to 1 at the end; 5 planes in total; 0000: point position; HHHHSSSS: color of each point |
|  41   |     Addressable image mode     |   pincture_index     |    Bidirectional   |   enum    |         No         | Value range: 0-19 |
|  43   |   Matrix screen rotate dir     |     screen_dir       |    Bidirectional   |  number   |         No         | Value range: 0-3 |
|  44   |      Power-on state            |    boot_status       |    Bidirectional   |  number   |         No         | Enum: 0: always on, 1: keep last state, 2: always off |
|  44   |      Working mode              |       mode           |    Bidirectional   |   enum    |         No         | Enum: 1: sleep mode, 2: reading mode, 3: leisure mode, 4: working mode |
|  45   |     Upper light brightness     |   up_brightness      |    Bidirectional   |  number   |         No         | Value range: 1-100 |
|  46   |     Lower light brightness     |  down_brightness     |    Bidirectional   |  number   |         No         | Value range: 1-100 |
|  47   |      Red light brightness      |   red_brightness     |    Bidirectional   |  number   |         No         | Value range: 1-100 |
|  48   |     Yellow light brightness    | yellow_brightness    |    Bidirectional   |  number   |         No         | Value range: 1-100 |
