### Motor DPID Definition

| DPID  |      Function       |    Identifier    | Data Transfer Type | Data Type | Support Automation |                                                        Function Attributes                                                         |
| :---: | :-----------------: | :--------------: | :----------------: | :-------: | :----------------: | :--------------------------------------------------------------------------------------------------------------------------------: |
|   1   |       Switch        |      switch      |    Bidirectional   |   enum    |         No         |                                   Value range: 0-3; 0: stop, 1: start                                                              |
|   2   |   Motor direction   |   control_back   |    Bidirectional   |   enum    |         No         |                                   Value range: 0-1; 0: default, 1: reversed                                                       |
|   3   |    Working state    |    work_state    |      Read-only     |   enum    |         No         |                                    Value range: 0-1; 0: forward, 1: reverse                                                       |
|   4   |  Percentage control | percent_control  |    Bidirectional   |  number   |         No         | Value range: 0-100, unit: %. The App sends the target percentage of user operation, and the device reports the current actual percentage |
|   5   |  Full-travel time   |    time_total    |    Bidirectional   |  number   |         No         |                                          Value range: 5-200, unit: s                                                              |
|   6   |      Countdown      |    countdown     |    Bidirectional   |  number   |         No         |                                        Value range: 0-86400, unit: s                                                             |
|   7   |    Fault alarm      |      fault       |      Read-only     |  number   |         No         |                                  Value range: 0-255, representing the fault number                                                    |
|   8   |  Backlight switch   | backlight_status |    Bidirectional   |   enum    |         No         | Value range: 0-2; 0: off, 1: on, 2: auto (lights up after physical operation, turns off after 30 seconds)                        |
|   9   |     Air volume      |       cfm        |    Bidirectional   |   enum    |         No         |                                  Value range: 0-2; 0: low, 1: medium, 2: high                                                     |
|  10   |      Oscillation    |      shake       |    Bidirectional   |   enum    |         No         |                    Value range: 0-2; 0: left-right, 1: up-down, 2: stop oscillating                                                |
|  11   |      Wind type      |    wind_class    |    Bidirectional   |   enum    |         No         | Value range: 0-5; 0: normal, 1: natural, 2: sleep, 3: forest, 4: maternal & infant, 5: AI smart                                   |
|  12   |      Display LED    |       led        |    Bidirectional   |   enum    |         No         |                                       Value range: 0-1; 0: off; 1: on                                                              |
|  13   |       Switch        |      switch      |    Bidirectional   |   enum    |        Yes         |                                        Enum value: 0-1; 0: off; 1: on                                                              |
|  14   |        Voice        |    sound_vol     |    Bidirectional   |  number   |         No         |                                       Value range: 1-10, AI voice volume                                                           |
|  15   |       Mute          |       mute       |    Bidirectional   |   enum    |         No         |                                       Value range: 0-1; 0: off, 1: on                                                              |
|  16   |   Fan speed level   |       gear       |    Bidirectional   |  number   |         No         |                                              Value range: 0-100                                                                   |
|  17   |        Auto         |       auto       |    Bidirectional   |   enum    |         No         |                                       Value range: 0, 1; (off, on)                                                                |
|  18   |   Cold air switch   | cold_air_switch  |    Bidirectional   |  number   |         No         |                                       Value range: 0-1; 0: off, 1: on                                                             |
|  19   | Temperature reading |     temp_get     |       One-way      |  number   |         No         |                                              Value range: 0-100                                                                   |
